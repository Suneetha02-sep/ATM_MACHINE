# ATM Machine Application

A console-based ATM Machine Application developed using **Java**. This project demonstrates fundamental Java programming concepts, conditional statements, user interaction, and basic banking operation logic.

## Overview

The ATM Machine Application simulates basic ATM functionality through a menu-driven console interface. Users can interact with the application to perform supported banking operations.

## Tech Stack

- **Programming Language:** Java
- **Execution Environment:** Java Runtime Environment (JRE)
- **Development Tools:** VS Code / IntelliJ IDEA / Eclipse

## Features

The application is designed around basic ATM operations, such as:

- User interaction through a console-based menu.
- Balance inquiry.
- Cash withdrawal.
- Cash deposit.
- Conditional checks for banking operations.
- Displaying transaction results.

## Getting Started

### Prerequisites

Make sure you have:

- Java Development Kit (JDK) installed.
- A code editor such as VS Code, IntelliJ IDEA, or Eclipse.
- Basic knowledge of Java.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Suneetha02-sep/ATM_MACHINE.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ATM_MACHINE
   ```

3. Open the project in your preferred Java IDE.

### Compile and Run

If your main Java file is named `Main.java`, use:

```bash
javac Main.java
java Main
```

If your main class has a different name, replace `Main` with the actual class name.

For projects using packages, compile and execute from the appropriate source directory.

## Application Workflow

1. Launch the application.
2. View the available ATM operations.
3. Select an operation from the menu.
4. Enter the required information.
5. View the corresponding result.
6. Return to the menu or exit the application.
